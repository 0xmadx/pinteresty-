# Etsy Scraper Data Output

This directory contains the raw and parsed data generated by the Antigravity Scraper, separated cleanly by the endpoint that produced it.

## Directory Structure

### 1. `search/` (Search Results Endpoint)
This folder contains the data fetched from the main search page (`https://www.etsy.com/search?q=...`).
- **`raw_response.html`**: The complete, unedited HTML payload returned by Etsy. This is the raw DOM used for parsing. It is fetched completely undetected by DataDome.
- **`parsed_results.json`**: The structured JSON data extracted from the raw HTML. It includes the `page_number` and a list of `items` containing the `title`, `price`, `url`, and `shop_name` for every listing on the page.

  **Example `parsed_results.json` Record:**
  ```json
  {
      "title": "2.2MM Solid Gold Birth Flower Ring Natural Inspired Leaf...",
      "url": "https://www.etsy.com/listing/4319864137/22mm-solid-gold...",
      "price": "123.34",
      "shop_name": null
  }
  ```

### 2. `suggest/` (Trending Suggestion Endpoint)
This folder contains the zero-input trending searches that Etsy displays before a user starts typing.
- **`trending.json`**: The raw JSON API response from Etsy's `/api/v3/ajax/public/search/zero-pane-trending-searches/true` endpoint. It contains trending search queries tailored to the current session.

  **Example `trending.json` Record:**
  ```json
  {
      "title": "dorm room decor",
      "search_term": "dorm room decor",
      "url": "https://www.etsy.com/search?q=dorm+room+decor...",
      "image": "https://i.etsystatic.com/42187191/r/il/d80dc0/8046747388/il_300x300...",
      "module_title": "Popular right now"
  }
  ```

### 3. `typing_suggest/` (Typing Autocomplete Endpoint)
This folder contains the predictive text suggestions Etsy provides while a user is typing a keyword into the search bar.
- **`typing.json`**: The raw JSON API response from Etsy's `/suggestions_ajax.php`. It contains a `results` array where each element has a `query` key representing an autocomplete suggestion based on the partial input provided by the scraper's typing simulation.

  **Example `typing.json` Record:**
  ```json
  {
      "query": "handmade jewelry",
      "search_types": [],
      "search_type_names": []
  }
  ```

## How to use this data
- Use **`search/parsed_results.json`** for building product databases, tracking pricing, and analyzing competitors.
- Use **`typing_suggest/typing.json`** to programmatically discover related long-tail SEO keywords. 
- Use **`suggest/trending.json`** to monitor global or localized trends on the platform.
